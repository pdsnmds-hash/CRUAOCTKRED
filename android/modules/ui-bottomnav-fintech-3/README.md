# ui-bottomnav-fintech-3

Нижняя капсула по референсу Modern Glass Variant 03: тёмно-синяя поверхность,
тонкая окантовка, градиент, скругление 28 dp и синяя подложка активной иконки.
Имитация стекла без размытия фона. Цвета декора вычисляются из BottomBarColors.

Пункты, подписи и иконки полностью задаёт продукт. Калькулятор может быть обычным
пунктом списка, но встроенного диалога и отдельной приподнятой кнопки здесь нет.
Публичный контракт слота сохранён. Floating = true; AppNavShell рисует панель поверх
контента и передаёт endReservation = 0.dp. Нижний системный inset учитывает сама панель.

Геометрия: внешние отступы 8 dp по горизонтали, 8 dp сверху и 16 dp снизу,
минимальная высота панели 70 dp, равные доли пунктов, иконка 21 dp в подложке 34 dp.
Длинные подписи сокращаются многоточием. При увеличении шрифта высота может расти.
Панель использует переданные ImageVector и не содержит собственных ресурсов.

Проверки из platform/:

```sh
./gradlew :ui-bottomnav-fintech-3:assembleDebug
./gradlew :ui-bottomnav-fintech-3:testDebugUnitTest
./gradlew :catalog-previews:recordRoborazziDebug
```

Снимки делает общий модуль :catalog-previews; файлы находятся в
catalog/pngs/ui-bottomnav-fintech-3*.png (320, 360 и 411 dp).
Unit-тесты проверяют видимость и нажатия пунктов на трёх ширинах, отсутствие
пересечений и выхода за боковые отступы, минимальные размеры областей нажатия,
управление выбранным пунктом извне и нулевой горизонтальный резерв оболочки.
Проверка на устройстве выполняется через node try-module.mjs в болванке.

Дизайн принят на ширинах 320, 360 и 411 dp.
На ширине 320 dp подпись «Калькулятор» сокращается многоточием.
